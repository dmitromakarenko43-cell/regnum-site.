ПВК «REGNUM» — стартовий макет сайту

ЩО Є:
- Адаптивний дизайн для телефона та комп'ютера.
- Чорний/червоний стиль.
- Навігація між розділами: головна, особовий склад, статут, підвищення, заяви/скарги, навчання, керівництво.
- Демонстраційні тексти українською.

ВАЖЛИВО:
Це лише frontend-прототип. Він НЕ має реальної авторизації, бази даних або захисту доступу. Не завантажуйте його як нібито закритий портал для справжніх персональних даних, доки не буде підключено серверну авторизацію та правила доступу.

Рекомендований наступний крок для повної версії:
1. Створити репозиторій GitHub і додати цей макет.
2. Перенести інтерфейс у Next.js.
3. Створити проєкт Supabase, увімкнути Auth та підтвердження електронної пошти.
4. Додати таблицю профілів учасників з ролями member/admin та статусом approved.
5. Увімкнути Row Level Security (RLS) для всіх таблиць; доступ дозволяти лише схваленим учасникам. Адмінські дії перевіряти сервером, а не тільки приховуванням кнопок.
6. Розгорнути Next.js через Vercel і налаштувати URL перенаправлення авторизації.
7. Перевірити в приватному вікні, що гість не може читати дані або відкривати адмін-функції.

Не публікуйте секретні ключі Supabase у коді клієнта. Ключ service_role ніколи не має потрапляти у браузер.
